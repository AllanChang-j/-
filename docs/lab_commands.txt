Stock Dashboard Lab Commands
============================

Use these commands on the lab computer.


1. Windows PowerShell, no Git, no Bash
-------------------------------------

Paste this whole command into PowerShell:

powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://github.com/AllanChang-j/-/archive/refs/heads/master.zip' -OutFile 'stock-dashboard.zip'; if (Test-Path stock-dashboard) { Remove-Item stock-dashboard -Recurse -Force }; Expand-Archive -Path 'stock-dashboard.zip' -DestinationPath '.' -Force; Rename-Item -LiteralPath '.\--master' -NewName 'stock-dashboard'; Set-Location stock-dashboard; powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1"


2. Windows PowerShell, already downloaded
-----------------------------------------

cd stock-dashboard
powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1


3. Windows PowerShell, already has Git
--------------------------------------

git clone https://github.com/AllanChang-j/-.git stock-dashboard
cd stock-dashboard
powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1


4. Windows PowerShell, update existing repo
------------------------------------------

cd stock-dashboard
git pull origin master
powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1


5. macOS / Linux / Git Bash
---------------------------

git clone https://github.com/AllanChang-j/-.git stock-dashboard && cd stock-dashboard && bash scripts/lab_one_click_level1.sh


6. macOS / Linux / Git Bash, update existing repo
------------------------------------------------

cd stock-dashboard && git pull origin master && bash scripts/lab_one_click_level1.sh


7. If Python is missing on Windows
---------------------------------

The PowerShell script will try to install Python 3.12 with winget.

If Python still cannot be found after installation, close PowerShell, open it again, then run:

cd stock-dashboard
powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1


8. Check NVIDIA GPU on Windows
------------------------------

nvidia-smi


9. Check Python / Torch / CUDA / LightGBM after setup
----------------------------------------------------

10. Use an existing data file on Windows
---------------------------------------

powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1 -DataPath "C:\path\to\taiwan_daily_ohlcv_20240101_20260630.csv"


11. Skip automatic data collection
----------------------------------

powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1 -CollectIfMissing 0


12. Run a different config on Windows
------------------------------------

powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1 -ConfigPath "config/lab_lightgbm_top80.yaml"
powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1 -ConfigPath "config/lab_lightgbm_top120.yaml"

19. Common fixes
----------------

PowerShell says "git is not recognized":

Use command 1. It downloads the GitHub zip without Git.

PowerShell says "bash is not recognized":

Use scripts/lab_one_click_level1.ps1 instead of the .sh script.

PowerShell blocks script execution:

powershell -ExecutionPolicy Bypass -File scripts/lab_one_click_level1.ps1

Folder already exists:

Remove-Item stock-dashboard -Recurse -Force

Then rerun command 1.

LightGBM is missing:

.\.venv\Scripts\python.exe -m pip install lightgbm

PyTorch CUDA is missing:

.\.venv\Scripts\python.exe -m pip install --upgrade torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
